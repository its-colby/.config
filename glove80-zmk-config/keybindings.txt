KEY BINDINGS
============
Keys are Graphite unless noted. Layer blocks: 4 stacked rows + thumb last.


--------------------------------------------------------------------------------
1. KEYBOARDS
--------------------------------------------------------------------------------
Internal (Mac builtin)
  Graphite via Karabiner + Goku

External (Glove80)
  Graphite via ZMK firmware (flash after keymap changes)

Both use Mac apps
  MonitorControl, Hammerspoon, Aerospace

OS input source
  U.S. QWERTY (not OS Graphite)

Cmd/Ctrl/Opt + Graphite letter = normal Mac shortcut (Cmd+S save, Cmd+V paste, …).


--------------------------------------------------------------------------------
2. SETUP (what must be running)
--------------------------------------------------------------------------------
  • MonitorControl  (Audio layer)
  • Hammerspoon     (S, T, W, D, L, F, O, U layers; Russian)
  • Aerospace       (N layer)
  • Karabiner+Goku  (all layers; internal keyboard only)


--------------------------------------------------------------------------------
3. HOW TO READ LAYERS
--------------------------------------------------------------------------------
  Hold Graphite KEY (QWERTY phys) — momentary layer name
  Each layer is 4 stacked rows (upper, home, bottom, thumb), keys inward → outward.
  Unmapped = unused. “thumb” = opposite-hand Space on that layer:
    left-hand hold → RT4; right-hand hold → LT4 (Mac: either Space).
  Punctuation keys on the left of = are spelled out (COMMA, PERIOD, …).
  Momentary = hold; toggle = tap on/off (see §8).

--------------------------------------------------------------------------------
6. DIFF (Mac vs Glove80)
--------------------------------------------------------------------------------
  Graphite source      Mac: Goku remap          Glove80: ZMK HID
  Audio hold           Mac: M                   Glove80: LT5 (M types alone)
  Russian toggle       Mac: hold X, tap H       Glove80: tap RT2
  Modifiers / Space    Mac: stock keys          Glove80: LT/RT thumbs (§5)
  Esc                  Mac: stock Esc           Glove80: left of B
  Arrows / edges       Mac: stock only          Glove80: under M/C/P/PERIOD + none pads
  Function row         Mac: stock Apple         Glove80: F1–F10 (§5)
  Brackets             Mac: phys RBKT / BSLH    Glove80: LBKT / RBKT cluster
  Layer Space          Mac: Space key    Glove80: opp. thumb (RT4 / LT4)

8. TOGGLE LAYERS
--------------------------------------------------------------------------------

--- Russian / Vestnik ---
Enable
  Glove80: tap RT2 (hold = RCtrl); tap again to leave
  Mac: hold X, tap H (Graphite)
  Requires Hammerspoon (vestnik.lua). Reload HS after edits; Accessibility on.

· = unchanged from English. * = hold → different letter (or stress).
Letter holds still open the same momentary layers (tap = Cyrillic).
