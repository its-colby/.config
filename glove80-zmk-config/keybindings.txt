KEY BINDINGS (current)
============================================
Keys in bindings are Graphite. Layer headers note Graphite hold key + QWERTY key.

DOC CONVENTION
- Every layer lists the full opposite-hand block (3 rows + Space), comma-separated per row.
- Unmapped keys: unused   (never "-" as a placeholder).
- A real hyphen/minus glyph: hyphen or minus.
- Center-column keys (Z/G/Y and ,/./etc.) are always included.
- Space = opposite-hand thumb action on the layer (see thumb note below).
- Hold/activation key is in the layer header as (Graphite X, QWERTY Y), not as a binding.
- Layer sections: upper/home/thumb × left/right; within each, inward → outward (toward pinky).
- DIFF — "Space" activation: Goku always uses the Space key (either thumb). Glove80 uses the
  opposite thumb from the hold hand: left-hand layers → right Space; right-hand layers → left Backspace.

ARCHITECTURE
- macOS input source: US/QWERTY only (do NOT enable OS Graphite — it remaps Glove80 too).
- Mac builtin Graphite: Goku/Karabiner (:is_built_in_keyboard / :builtin only).
- Glove80 Graphite: ZMK firmware HID letters.
- Apps: Hammerspoon hyper chords → ~/.config/bin/open-or-focus.
- Window management: Aerospace (Alt+Shift chords).
- Karabiner never targets Glove80.
- Glove80 layer holds: opposite hand only (LAYER_LEFT / LAYER_RIGHT).
  Goku can bind same-hand keys too — see DIFF notes where that matters.

BASE LAYER — PUNCTUATION (both, unless noted)
================================================================================
, (left of F) → comma ; Shift = "
. (next to P) → period ; Shift = !
- (next to .) → hyphen ; Shift = _
/ (under I) → ; ; Shift = :
' (right of I) → / ; Shift = \
? (right of J) → ? ; Shift = |

Brackets / curly:
  DIFF — physical placement differs; same glyphs:
  - Mac (Goku): phys ] → [/{ ; phys \ → ]/}
  - Glove80: LBKT → [/{ ; RBKT → ]/}
  - Glove80 right-of-J alpha key (\ position) → ?/| (same as Mac phys [)

================================================================================
BASE LAYER — THUMB / BOTTOM HOLDS (how layers are triggered)
================================================================================
DIFF — activation keys differ; layer contents match.

Glove80 thumbs (inner → outer):
  Left bottom: Backspace | Tab (tap) / Audio hold | Alt
  Left top: Shift | Caps Lock | Lower
  Right: Alt | Enter (tap) / Word-Nav hold | Space (tap) / Word-Del hold
  Also: Shift + RCtrl (Russian toggle tap) on right top thumb row.
  Glove80 only — tap RCTRL (2nd top-right thumb, hold still RCtrl) toggles Vestnik Russian (L_RU).

Mac (Goku) — stock Tab/Shift/Backspace/Delete stay put.
  Bottom-row holds under index fingers:
  phys B (Graphite V alone) → Audio hold
  phys N (Graphite K alone) → Word Deletion hold
  phys M (Graphite P alone) → Word Navigation hold
  (Glove80 left thumbs differ; Mac uses real Tab/Caps/Ctrl)

================================================================================
QUICK DIFF SUMMARY (Goku vs Glove80)
================================================================================
1. Graphite implementation: Goku remaps builtin only; Glove80 sends Graphite HID.
2. Layer activation: Goku bottom-row holds (B/N/M); Glove80 real thumbs (Tab-hold Audio / Space / Enter).
3. Left thumbs: Glove80 Backspace | Tab | Caps-on-LCtrl-slot; Mac keeps stock Tab/Caps/Ctrl.
4. Edge media (Vol/Bri next to B/N/Q/X): Glove80 only.
5. Bracket keys: Mac phys ]+\ ; Glove80 LBKT/RBKT cluster.
6. Russian Vestnik toggle (RCTRL tap): Glove80 only.
7. Opposite-hand-only layers on Glove80; Goku may use same-hand bindings.
