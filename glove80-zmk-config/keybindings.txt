KEY BINDINGS (current)
============================================
Keys in bindings are Graphite. Layer headers note Graphite hold key + QWERTY key.

DOC CONVENTION
- Every layer lists the full opposite-hand block (3 rows + Space), comma-separated per row.
- Unmapped keys: unused   (never "-" as a placeholder).
- A real hyphen/minus glyph: hyphen or minus.
- Center-column keys (Z/G/Y and ,/./etc.) are always included.
- Space = opposite-hand thumb action on the layer (see thumb note below).
- Hold/activation key is in the layer header as (Graphite X, QWERTY Y), not as a binding.
- Layer sections: upper/home/thumb × left/right; within each, inward → outward (toward pinky).
- DIFF — "Space" activation: Goku always uses the Space key (either thumb). Glove80 uses the
  opposite thumb from the hold hand: left-hand layers → right Space; right-hand layers → left Backspace.

ARCHITECTURE
- macOS input source: prefer **Unicode Hex Input** as the daily layout (US-compatible;
  required for Russian / math / IPA / … / — macros). Do NOT enable OS Graphite.
- Mac builtin Graphite: Goku/Karabiner (:is_built_in_keyboard / :builtin only).
- Glove80 Graphite: ZMK firmware HID letters.
- Apps: Hammerspoon hyper chords → ~/.config/bin/open-or-focus.
- Window management: Aerospace (Alt+Shift chords).
- Karabiner never targets Glove80.
- Glove80 layer holds: opposite hand only (LAYER_LEFT / LAYER_RIGHT).
  Goku can bind same-hand keys too — see DIFF notes where that matters.


================================================================================
BASE LAYER — LETTERS (Graphite)
================================================================================
Both keyboards type the same Graphite alphas (OS stays US).
Letters: Shift = uppercase (not listed).

  b l d w z    , f o u j  ?
  n r t s g    y h a e i  /
  q x m c v    k p . -  ;

Shifted:
               "          |
                          \
                   ! _  :

Hold letters (layer taps / simlayers), inward → outward:
  Upper left:  W D L
  Upper right: F O U
  Home left:   S (primary apps) T (secondary) R (inner nav) N (window)
  Home right:  H (browser) A (clipboard) E (selection) I (find)
  (other letters type alone, including B)


================================================================================
BASE LAYER — PUNCTUATION (both, unless noted)
================================================================================
, (left of F) → comma ; Shift = "
. (next to P) → period ; Shift = !
- (next to .) → hyphen ; Shift = _
/ (under I) → ; ; Shift = :
' (right of I) → / ; Shift = \   (Glove80: Shift released before \ so it is not pipe)
? (right of J) → ? ; Shift = |

Number row (Glove80):
  Left of 1 → F13 (was =)
  Right of 0 → = ; Shift = +
  Hyphen/underscore: still on Graphite - (next to .)

Brackets / curly:
  DIFF — physical placement differs; same glyphs:
  - Mac (Goku): phys ] → [/{ ; phys \ → ]/}
  - Glove80: LBKT → [/{ ; RBKT → ]/}
  - Glove80 right-of-J alpha key (\ position) → ?/| (same as Mac phys [)

BASE LAYER — GLOVE80-ONLY EDGE KEYS
================================================================================
(Not on Mac; Mac keeps stock Tab/Esc/Home/End there.)

Left of B → Escape
Left of N → F11
Left of Q → F12
Under Q → Brightness Down
Under X → Brightness Up

Top F-row (Glove80 only):
  F1 = Brightness Down , F2 = Brightness Up
  F3 = Cmd+= (zoom in) , F4 = Cmd+- (zoom out)
  F5 = F5
  F6 = Next track , F7 = Play/Pause , F8 = Mute
  F9 = Volume Down , F10 = Volume Up

Brightness: C_BRI_* only drives the built-in (or Apple) panel. External monitors need
MonitorControl (or Lunar) to listen to the same keys and optionally sync all displays.

================================================================================
BASE LAYER — THUMB CLUSTERS
================================================================================
Orientation (split): outer = toward letter keys / outside of body;
inner = toward the gap between halves (like G inner vs S outer; Y inner vs H outer).

Left — outer → inner
  Top:    Shift (hold) | Control (hold) | Command (hold)
  Bottom: Backspace    | Tab (tap) / Audio (hold) | Caps Lock (tap toggle)

Right — outer → inner
  Top:    Shift (hold) | Control (hold) / Russian tap | Command (hold)
  Bottom: Space (tap) / Word-Del (hold) | Enter (tap) / Word-Nav (hold) | Alt (hold)

Mods are hold-only (tap alone does nothing useful). Russian: tap right-top middle.

================================================================================
GLOVE80 STOCK LAYERS (not mirrored in Goku)
================================================================================
LOWER: MoErgo stock numpad/nav layer (still in firmware; not on a thumb currently).
MAGIC (magic key): Bluetooth profiles, RGB, bootloader, factory test.

RUSSIAN (L_RU) — Vestnik (Вестник), Glove80 only
- Toggle: tap right-top middle (Control key). Hold = RCtrl.
  Tap again → back to DEFAULT.
- OS must include **Unicode Hex Input** (System Settings → Keyboard → Input Sources).
  Keep it selected (or switch to it) when using Russian / math / IPA unicode macros.
  U.S. alone is not enough — Option+hex only emits Cyrillic under Unicode Hex Input.
- Do NOT rely on OS “Russian - Phonetic” for this layer (layout won’t match Vestnik).
- Alphas on Graphite positions:

  ц д р г х    ф п а я э
  с т н к б    ь в о е и
  ш з л м ч    ж й ы у ю

- Extras:
  RIGHT (under C) = щ
  UP (under P) = ъ
  DOWN (under .) = ё
  Backspace thumb (opp. Space) = ́ combining acute (stress on preceding vowel)
  right of J = . ; Shift = ;
  right of I = , ; Shift = — (em dash)
  [ ] (left of PgDn) = « »


================================================================================
QUICK DIFF SUMMARY (Goku vs Glove80)
================================================================================
1. Graphite implementation: Goku remaps builtin only; Glove80 sends Graphite HID.
2. Layer activation: Goku Graphite M / . / P holds; Glove80 Tab / Enter / Space holds + letter holds.
3. Thumbs (outer→inner): L Shift/Ctrl/Cmd + Bspc/Tab(+Audio)/Caps; R Shift/Ctrl(+RU)/Cmd + Space(+WDel)/Enter(+WNav)/Alt.
4. Edge keys left of B/N/Q: Esc / F11 / F12 (Glove80 only). Bri under Q/X still.
5. Bracket keys: Mac phys ]+\ ; Glove80 LBKT/RBKT cluster.
6. Russian Vestnik toggle (RCTRL tap): Glove80 only.
7. Opposite-hand-only layers on Glove80; Goku may use same-hand bindings.
