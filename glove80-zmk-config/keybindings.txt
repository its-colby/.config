KEY BINDINGS (current)
============================================
Keys in bindings are Graphite. Layer headers note Graphite hold key + QWERTY key.

DOC CONVENTION
- Every layer lists the full opposite-hand block (3 rows + Space), comma-separated per row.
- Unmapped keys: unused   (never "-" as a placeholder).
- A real hyphen/minus glyph: hyphen or minus.
- Center-column keys (Z/G/Y and ,/./etc.) are always included.
- Space = opposite-hand thumb action on the layer (see thumb note below).
- Hold/activation key is in the layer header as (Graphite X, QWERTY Y), not as a binding.
- Layer sections: upper/home/thumb × left/right; within each, inward → outward (toward pinky).
- DIFF — "Space" activation: Goku always uses the Space key (either thumb). Glove80 uses the
  opposite thumb from the hold hand: left-hand layers → RT4; right-hand layers → LT4.

THUMB KEY IDS (Glove80)
- LT = left half thumbs, RT = right half thumbs.
- Numbered outward → inward, top row then bottom row:
    LT1 LT2 LT3      RT3 RT2 RT1     (upper row)
    LT4 LT5 LT6      RT6 RT5 RT4     (lower row)
  (RT mirrored: RT1 is toward the letter keys / outside of the body, same as LT1.)
- Diagram (outer ← → inner toward the split):

    Left                          Right
    LT1  LT2  LT3          RT3  RT2  RT1
    LT4  LT5  LT6          RT6  RT5  RT4

ARCHITECTURE
- macOS input source: plain **U.S.** is fine. Do NOT enable OS Graphite.
  (Unicode Hex Input is no longer required — Glove80 symbols go through Hammerspoon.)
- Cmd/Ctrl/Opt + Graphite letter = normal Mac shortcut for that letter (Cmd+S save,
  Cmd+V paste, Cmd+C copy, Cmd+F find, …). Mac: Goku `##` remaps keep modifiers.
  Glove80: firmware already sends Graphite HID with mods.
- Glove80 unicode (math / IPA / logic / … / — / stress): firmware sends F15 + 4 hex
  digits; Hammerspoon `unicode_leader.lua` types the glyph (same idea as Vestnik).
- Russian (Vestnik): Hammerspoon eventtap (`vestnik.lua`). Global once on (Glove80 + Mac).
  Glove80: F16 on / F17 off with the Russian layer.
  Mac builtin: hold Graphite X, tap Graphite H (phys J) → F18 (Goku) → Hammerspoon toggle.
- Mac builtin Graphite: Goku/Karabiner (:is_built_in_keyboard / :builtin only).
- Glove80 Graphite: ZMK firmware HID letters.
- Mac symbol layers: Goku clipboard paste (already fast).
- Apps: Hammerspoon hyper chords → ~/.config/bin/open-or-focus.
- Window management: Aerospace (Alt+Shift chords).
- Karabiner never targets Glove80.
- Glove80 layer holds: opposite hand only (LAYER_LEFT / LAYER_RIGHT).
  Goku can bind same-hand keys too — see DIFF notes where that matters.

BASE LAYER — PUNCTUATION (both, unless noted)
================================================================================
, (left of F) → comma ; Shift = "
. (next to P) → period ; Shift = !
- (next to .) → hyphen ; Shift = _
/ (under I) → ; ; Shift = :
' (right of I) → / ; Shift = \   (Glove80: Shift released before \ so it is not pipe)
? (right of J) → ? ; Shift = |

Number row (Glove80):
  Left of 1 → none
  Right of 0 → = ; Shift = +
  Hyphen/underscore: still on Graphite - (next to .)

Brackets / curly:
  DIFF — physical placement differs; same glyphs:
  - Mac (Goku): phys ] → [/{ ; phys \ → ]/}
  - Glove80: LBKT → [/{ ; RBKT → ]/}
  - Glove80 right-of-J alpha key (\ position) → ?/| (same as Mac phys [)

================================================================================
BASE LAYER — THUMB CLUSTERS (Glove80 LT/RT)
================================================================================
See THUMB KEY IDS above. Outer = toward letter keys; inner = toward the split.

Default layer
  LT1 = Shift (hold)          RT1 = Shift (hold)
  LT2 = Control (hold)        RT2 = Control (hold) / Russian (tap → L_RU)
  LT3 = Command (hold)        RT3 = Command (hold)
  LT4 = Backspace             RT4 = Space (tap) / Word-Del (hold)
  LT5 = Tab (tap) / Audio (hold)   RT5 = Enter (tap) / Word-Nav (hold)
  LT6 = Caps Lock             RT6 = Alt (hold)

Russian layer (L_RU) — deltas vs default
  LT1–LT4 = same (Shift / Ctrl / Cmd / Backspace)
  LT5 = Stress ́ (tap; applies to previous letter) / Audio (hold)
  LT6 = none  (was Caps)
  RT1 = Shift                 RT2 = Control (hold) / leave Russian (tap)
  RT3 = Command
  RT4–RT6 = same (Space+Word-Del / Enter+Word-Nav / Alt)

Mods on LT1–3 / RT1 / RT3 are hold-only. Enter/leave Russian: tap RT2.

- Toggle (Glove80): tap RT2. Hold RT2 = RCtrl.
  Tap on → F16 + layer on; tap off → F17 + &to DEFAULT.
- Toggle (Mac builtin): hold Graphite X, tap Graphite H (physical J).
  Goku sends F18; Hammerspoon toggles the same global eventtap.
- L_RU sits *under* letter/thumb layers so hold-R / hold-S / etc. still work in Russian.

- Cyrillic is NOT Unicode Hex. Graphite Latin HID → Hammerspoon Vestnik glyphs.
- Math / IPA / logic: F15 + hex → Hammerspoon (not OS Hex Input).
- Reload Hammerspoon after vestnik/unicode_leader changes. Accessibility required.
- Layers still work in Russian mode (same letter holds / thumbs as base).
  Vestnik only emits Cyrillic on tap for layer keys; hold opens the layer.
- Alphas on Graphite positions:

  ш з л м ч    ж й ы у ю

  hold ш (Q) = щ ; Shift+hold = Щ

  hold э (J) = ё ; Shift+hold = Ё

================================================================================
QUICK DIFF SUMMARY (Goku vs Glove80)
================================================================================
1. Graphite implementation: Goku remaps builtin only; Glove80 sends Graphite HID.
2. Layer activation: Goku Graphite M / . / P holds; Glove80 LT5 / RT5 / RT4 holds + letter holds.
3. Thumbs: LT1–3 Shift/Ctrl/Cmd; LT4–6 Bspc/Tab(+Audio)/Caps; RT1–3 Shift/Ctrl(+RU)/Cmd; RT4–6 Space(+WDel)/Enter(+WNav)/Alt.
4. Edge keys left of B/N/Q: Esc / none / none. Under Q/X none; under M/C/P/. = arrows. F5/Pg± = none.
5. Bracket keys: Mac phys ]+\ ; Glove80 LBKT/RBKT cluster.
6. Russian Vestnik (tap RT2): Glove80 + Hammerspoon F16/F17; not Hex.
7. Opposite-hand-only layers on Glove80; Goku may use same-hand bindings.
