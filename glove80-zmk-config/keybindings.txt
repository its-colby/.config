KEY BINDINGS
============
Keys are QWERTY. Layer blocks: 4 stacked rows + thumb last.
Finger positions match the old Graphite layout (e.g. Primary apps = left index = F).


--------------------------------------------------------------------------------
1. KEYBOARDS
--------------------------------------------------------------------------------
Internal (Mac builtin)
  Stock QWERTY · layers via Karabiner + Goku

External (Glove80)
  QWERTY via ZMK firmware (flash after keymap changes)

Both use Mac apps
  MonitorControl, Hammerspoon, Aerospace

OS input source
  U.S. QWERTY

Cmd/Ctrl/Opt + letter = normal Mac shortcut (Cmd+S save, Cmd+V paste, …).


--------------------------------------------------------------------------------
2. SETUP (what must be running)
--------------------------------------------------------------------------------
  • MonitorControl  (Audio layer)
  • Hammerspoon     (F, D, R, E, W, U, I, O layers; Russian)
  • Aerospace       (A layer)
  • Karabiner+Goku  (all layers; internal keyboard only)


--------------------------------------------------------------------------------
3. HOW TO READ LAYERS
--------------------------------------------------------------------------------
  Hold KEY — momentary layer name
  Each layer is 4 stacked rows (upper, home, bottom, thumb), keys inward → outward.
  Unmapped = unused. “thumb” = opposite-hand Space on that layer:
    left-hand hold → RT4; right-hand hold → LT4 (Mac: either Space).
  Punctuation keys on the left of = are spelled out (COMMA, PERIOD, …).
  Momentary = hold; toggle = tap on/off (see §8).

--------------------------------------------------------------------------------
6. DIFF (Mac vs Glove80)
--------------------------------------------------------------------------------
  QWERTY source         Mac: stock                  Glove80: ZMK HID
  Audio hold            Mac: C                      Glove80: LT5 (C types alone)
  Russian toggle        Mac: hold G, tap K          Glove80: hold G, tap K (RT2 still works)
  Mouse                 both: hold G, tap J
  Game mode             Mac: (none)                 Glove80: tap RT3 (hold = RCmd)
  Modifiers / Space     Mac: stock keys             Glove80: LT/RT thumbs (§5)
  Esc                   Mac: stock Esc              Glove80: left of Q
  Arrows / edges        Mac: stock only             Glove80: under C/V/M/COMMA; PgUp/PgDn; click under Esc
  Function row          Mac: stock Apple            Glove80: F1–F10 (§5)
  Brackets              Mac: stock [ ]              Glove80: LBKT / RBKT cluster
  Layer Space           Mac: either Space key       Glove80: opp. thumb (RT4 / LT4)

8. TOGGLE LAYERS
--------------------------------------------------------------------------------

--- Game (Glove80 only) ---
Enable / leave: tap RT3 (hold RT3 = RCmd). Mac: none.

On: plain QWERTY letters/punct (no hold layers). F-row bri/vol/media,
numbers, Magic, mods, Space/Enter/arrows unchanged. LT5 = none (no Audio).
LT6 = Tab. RT2 = plain RCtrl (no Russian). M / COMMA = plain (no
Word-Del / Word-Nav). PgUp/PgDn + click under Esc still work.


--- Mouse ---
Enable / leave: hold G, tap J (Mac + Glove80).

Bottom row (hold to keep moving)
  Z left · X up · C down · V right
  M up-left · COMMA up-right · PERIOD down-left · FSLH down-right
  B left click · N right click
Arrows: ↑ scroll up · ↓ scroll down · ← scroll left · → scroll right
Home: tap F = lock left click · tap J = release
  hold F / J = Primary apps / Browser (same as off mouse)
Bottom row holds (Word-Del, Word-Nav, Mac C-audio) are off — those keys move the pointer.


--- Russian / Vestnik ---
Enable
  both: hold G, tap K
  Glove80 also: tap RT2 (hold = RCtrl); tap again to leave
  Requires Hammerspoon (vestnik.lua). Reload HS after edits; Accessibility on.

· = unchanged from English. * = hold → different letter (or stress).
Letter holds still open the same momentary layers (tap = Cyrillic).
