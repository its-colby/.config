PROPOSED 14 LAYERS (4 home-row actions each)
============================================
Budget: home-row holds A S D F + J K L ;, plus 3 left thumbs (BSPC / DEL / LAlt) and 3 right thumbs (RAlt / Enter / Space).
Each layer = hold that key → 4 actions on the opposite home row. Thumb taps stay: Backspace, Delete, Enter, Space, etc.
Numbers, full symbol rows, unicode/math, media, recording → not in this set (base layout / Lower / later).

RIGHT-HAND HOLDS → left home row A S D F
- J  tab create/close:     new tab/window | close tab/pane | split horizontal | split vertical
- K  tab/pane focus:       prev window/pane | next window/pane | prev tab/pane | next tab/pane
- L  aerospace focus:      workspace 1 | workspace 2 | focus prev tile | focus next tile
- ;  aerospace arrange:    move → ws1 | move → ws2 | tiles layout | accordion layout

LEFT-HAND HOLDS → right home row J K L ;
- A  apps:                 Cursor | Arc | Terminal | Slack (swap to taste)
- S  symbols (top 4):      = | - | _ | /
- D  wrappers:             () | [] | {} | ""
- F  code jump:            quick open (Cmd+P) | command palette | go to definition | navigate back

LEFT THUMBS → right home row J K L ;
- BSPC  delete:            delete word left | delete word right | delete to line start | delete to line end
- DEL   move by unit:      word left | word right | line start | line end
- LAlt  select/extend:     select word left | select word right | select to line start | select to line end

RIGHT THUMBS → left home row A S D F
- RAlt  find:              find | find next | find prev | rename
- Enter clipboard:         copy | cut | paste | select all
- Space edit core:         undo | redo | save | Escape

Out of this 14 (on purpose): plain arrows, indent/deindent, Shift+Enter/Tab-as-layer, full number rows, unicode, volume, browser link next/prev, scroll/Home/End, more workspaces 3–4, app extras — park on upper rows, Lower, or a later expansion.
